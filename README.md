# 🎯 Guess The Number

A fun and interactive number guessing game built with HTML, CSS and JavaScript!

---

## 🎮 How to Play

1. A random number between **1 and 100** is generated
2. You have **10 attempts** to guess the correct number
3. After each guess the game tells you if your guess is **Too High** or **Too Low**
4. Try to guess the number before you run out of attempts!

---

## ✨ Features

- 🎲 Random number generation every new game
- 🔢 10 attempts per game
- 💬 Live feedback after every guess
- 📝 Previous guesses are tracked and displayed
- 🔄 Reset button to start a new game

---

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (Vanilla)
